## 課程內容摘要

### 第 1-2 週：環境與數據基礎
- Day 1-7：安裝環境、熟悉介面
- Day 8-14：數據獲取、基礎統計

### 第 3-4 週：回測入門
- 均值回歸策略
- MA 交叉策略
- 績效指標解讀

### 第 5-6 週：投資組合優化
- Maximum Sharpe
- Minimum Volatility
- Risk Parity (HRP)
- Black-Litterman

### 第 7-8 週：風險管理
- VaR（歷史法、參數法、蒙地卡羅）
- CVaR / Expected Shortfall
- 最大回撤分析

### 第 9-10 週：統計套利
- 協整檢定
- 配對交易
- 半衰期計算

### 第 11 週：動量策略
- 經典動量
- 趨勢跟蹤（ADX）
- 雙重動量
- 突破策略

### 第 12 週：穩健性測試
- Walk-Forward Optimization
- Overfitting Ratio
- 參數穩定性

### 第 13 週+：自訂策略開發
- 策略設計與實現
- 完整回測流程
- 模擬交易
- 實盤準備
