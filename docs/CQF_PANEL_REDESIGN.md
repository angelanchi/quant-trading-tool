### 若方向不可行的替代方案

- 資料源（FinMind/yfinance）不可用 → 面板自動改用標示清楚的模擬資料，仍可學習模型。

- ML 模型打不贏基準 → 面板如實顯示「無預測力」，不隱藏。

## 3. 「老師投資 insights」評估結論

6 份 PDF 不是可量化的交易規則。內容符合「投資社團統一佈局」拉高出貨結構：
報酬承諾 30–60%／3–7 交易日、依資金分陣營、早期陣營「配合洗盤、震倉」、
後期陣營在「波段後期」進場、經助理收集資金資訊、限期報名。

因此規則層改為 **⑤ 說法驗證器**：把任何報酬承諾轉成 GBM 下的發生機率。
可保留並以資料驗證的部分：結算日波動、融資水位、週期位置、停損紀律。

## 5. 頁面資訊架構與工作流程

```
側欄（每頁都有）
├─ 工作流程範本 ── 決定左側「決策流程」列出哪些步驟、順序為何
├─ 研究標的 ────── ①–⑥ 共用；任何一頁更換，其他頁同步
├─ 本次決策紀錄 ── 已帶出的結果（盤勢、目標／停損、股數）
├─ ＋ 新增觀測代號 ─ 驗證格式 → 下載還原權值價格 → 寫入 watchlists.json
└─ 管理觀察清單 ── 移除代號、群組改名、建立新群組

資料傳遞（views/_state.py）
① 盤勢 ──波動體制──▶ ④ 單筆風險預設（高波動 0.5%，否則 1%）
③ 情境定價 ──目標、停損、觸價機率、σ──▶ ④ 停損方式「沿用 ③ 停損」
④ 部位 ──股數、進場價、停損、虧損上限──▶ ⑥ 交易表單預填（含台股手續費與備註）
```

| 範本 | 步驟 | 用途 |
|---|---|---|
| 完整流程 | ①→②→③→④→⑤→⑥ | 從盤勢到下單紀錄 |
| 每日盤前檢查 | ①→④ | 市場危險程度＋持股組合 VaR |
| 新標的研究 | ②→③→④→⑥ | 比較 → 機率 → 部位 → 紀錄 |
| 持股覆盤 | ⑥→④ | 回顧交易，再看組合風險 |

- 不在範本內的步驟列在「其他步驟」，仍可直接開啟。
- 每頁上方顯示範本進度；只有真的產出結果的步驟會打勾。每頁下方有「下一步」連結。
- 研究標的與計畫存於 `data/session_ctx.json`，重新整理或重開面板仍保留。計畫只屬於一個標的；更換標的會清空計畫。
- 新增代號會先下載價格，下載失敗就不加入，避免清單出現無資料的代號。每週排程以 `--all` 讀取整份清單，新代號自動納入。
- 工具箱：原 `pages/` 頁面保留。CQF 實驗室：固定收益、CQF 概念地圖。
- 每頁底部有「CQF 概念」區塊，格式固定：這是什麼／為什麼重要／公式／程式位置／在面板怎麼用。

## 6. 資料管線

```
每週六 06:55（Claude 排程任務，需電腦開機）
  └─ scripts/fetch_market_data.py --all   （只用 Python 標準庫）
       ├─ Yahoo Finance：還原權值價格（主要來源）
       ├─ FinMind TaiwanStockPrice + TaiwanStockDividendResult：Yahoo 失敗時的台股備援，自行還原除權息
       └─ FRED：DGS10 / DGS2 / DGS3MO 美債殖利率
  └─ data/prices/*.csv + _manifest.json  →  面板優先讀取
```

| 項目 | 說明 |
|---|---|
| 執行位置 | 只能在使用者的 Windows 本機；雲端與沙箱被網路白名單阻擋 |
| 讀取順序 | 本機 CSV → 即時 API → DEMO 模擬資料（有警示） |
| 美股基準 | SPY；未下載到時自動改用 VOO（同一指數） |
| 已知限制 | FinMind 還原資料集與 Finnhub 歷史 K 線需付費；Yahoo 大量請求後會暫時拒絕 |
| 手動更新 | 首頁「更新真實資料」按鈕，或 `run.bat fetch` |

## 7. 視覺風格

採單一風格「投行研究報告風」，全部頁面一致。

| 元素 | 規則 |
|---|---|
| 版頭 | 產品名、日期、資料截至日，下方深藍粗線 |
| 重點摘要 | 每頁開頭 3–5 點，數字由當下計算結果自動產生 |
| 圖表標題 | 「圖 N　結論句」，例如「目前波動 18.7%，位於歷史第 50 百分位」 |
| 資料來源 | 每張圖下方註明來源與截至日 |
| 色彩 | 深藍主色 #1F3B5C、淡藍輔色 #7399C6，其餘灰階 |
| 字體 | Arial / Noto Sans TC（系統字型，不需額外字型檔） |
| 漲跌色 | 依台灣慣例：紅漲綠跌（K 線、MACD 柱、漲跌標記、指標卡漲跌幅） |
| 金額 | 台股顯示「元」、美股顯示「US$」；台美混合的加總標示「混合幣別」（不做匯率換算） |
| 適用範圍 | 決策流程、CQF 實驗室、工具箱全部頁面；舊頁面的圖表經 `style_figure()` 統一套色與編號 |

## 8. 刻意不做

- **M5 深度學習**：日頻資料樣本小，深度模型容易過擬合。等 M4 基準驗證可行後再加。
- **自動下單**：本面板是決策輔助，不是交易系統。

## 9. 驗證方式

- 數學模組以教科書數值驗證（Hull BS 範例、Put-Call parity、GBM 期望值）。
- `pytest` 全部通過。
- 每頁實際啟動並截圖檢查。
